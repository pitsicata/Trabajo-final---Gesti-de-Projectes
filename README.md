# Trabajo final: Monitorización del Consumo de Agua en la UAB

## Objetivos y Finalidades
El objetivo principal de este proyecto es desarrollar una herramienta web interactiva que permita visualizar, analizar y concienciar sobre el consumo de agua en la Universitat Autònoma de Barcelona.

## Criterios Mínimos de Éxito
- **Prototipo:** Diseño visual previo de la interfaz de usuario.
- **Página Web:** Desarrollo de una web funcional que muestre métricas y gráficos claros sobre el gasto de agua.
- **Análisis de Datos:** Procesamiento estructurado de la información oficial obtenida del portal de sostenibilidad de la UAB.
